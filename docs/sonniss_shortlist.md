# Sonniss GDC bundles — what to download

Built 2026-10-15 from the public tracklists (2016–2024 sheets + the 2026 filelist), about 5,500 files across
~1,840 libraries. **Every library in a GDC bundle is a 1–4 file sample**, so a library is worth having
only if those few files land on something we need. The library names below are as written in the tracklists.

Download only to `E:\Audio\Sonniss\<year>\`, never inside the project: Godot would import every WAV.
License: royalty-free, commercial, no credit; no redistribution of the raw files; no AI training.

**B1** = feeds Batch 1 of `docs/suno_sfx_prompts.md` (combo-drop exhale + fire/arcane/martial channel loops).
